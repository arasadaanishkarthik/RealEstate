## 🌍 About the Project

**EstateLand** is a premium real estate website focused on high-end land and open-plot investments. The platform presents available properties through a cinematic, luxury-focused interface designed to make property discovery more engaging. It combines modern visual design with smooth scrolling, parallax effects, glassmorphism elements, and interactive property showcases. The website is intended for users exploring premium land investment opportunities and for showcasing real-estate projects in a polished digital experience.

## ✨ Key Features

- 🏡 **Premium Real Estate Showcase** — Present land and open-plot investment opportunities.
- 🌍 **Property Discovery** — Browse available estates and projects.
- 📋 **Plot Details** — Dedicated pages for viewing individual property information.
- 🎬 **Cinematic Visual Design** — Immersive visuals designed around a luxury real-estate experience.
- ✨ **Glassmorphism UI** — Modern translucent interface elements and visual effects.
- 🖱️ **Smooth Scrolling** — Enhanced navigation and scrolling experience.
- 🌊 **Parallax Effects** — Layered motion effects throughout the experience.
- 📱 **Responsive Interface** — Designed for different screen sizes.
- 🧭 **Multi-Page Navigation** — Separate pages for the homepage, estates, property details, and information.
- 📞 **Concierge / Contact Section** — Dedicated contact-oriented experience for prospective customers.
- 🎥 **Video Assets** — Includes video resources used by the website's visual experience.
